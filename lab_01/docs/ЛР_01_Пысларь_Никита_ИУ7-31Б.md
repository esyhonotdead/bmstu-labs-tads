# Лабораторная работа № 1

Обработка больших чисел - Вариант № 3

## Техническое задание

### Цель работы

Реализовать арифметическую операцию над числами, выходящими за разрядную сетку стандартных числовых типов, и выбрать структуры данных для их хранения и обработки.

### Условие задачи

Смоделировать умножение целого числа длиной не более 40 десятичных цифр на действительное число в форме `±m.nE±K`. Суммарная длина мантиссы действительного числа не должна превышать 30 значащих цифр, а порядок должен содержать не более пяти цифр. Результат необходимо вывести в форме `±0.m1E±K1`, где `m1` содержит не более 40 значащих цифр, а `K1` содержит не более пяти цифр.

Если точное произведение содержит больше 40 значащих цифр, необходимо округлить его по 41-й цифре. При некорректных исходных данных или выходе порядка результата за допустимые границы программа должна вывести сообщение об ошибке.

### Исходные данные

Числа передаются через стандартный поток ввода, каждое на отдельной строке. Первым вводится целое число, вторым действительное.

| Данные | Формат | Ограничения |
| --- | --- | --- |
| Целое число | Необязательный знак `+` или `-`, затем десятичные цифры | Не более 40 цифр; точка и порядок запрещены |
| Мантисса действительного числа | Необязательный знак, цифры и не более одной точки | Не более 30 значащих цифр по условию задания; должна присутствовать хотя бы одна цифра |
| Порядок действительного числа | `E` или `e`, необязательный знак и цифры | От `-99999` до `+99999`, не более пяти цифр в записи |

### Аварийные ситуации

Программа обрабатывает отсутствие строки во входном потоке, пустую строку, превышение размера буфера, неверный формат числа, превышение длины целого числа, мантиссы или порядка, а также выход порядка результата за допустимый диапазон.

## Структуры данных

### Представление целого числа

```c
#define BIG_INT_MAX_DIGITS 40

typedef struct
{
    int sign;
    size_t len;
    unsigned char digits[BIG_INT_MAX_DIGITS];
} big_int_t;
```

Поле `sign` равно `1` для неотрицательного числа и `-1` для отрицательного. Поле `len` содержит число используемых элементов массива. Каждый элемент `digits` хранит числовое значение одной десятичной цифры от 0 до 9, а не её символьный код. Цифры расположены от старшей к младшей: число `123` представляется массивом `{1, 2, 3}` с длиной 3.

Ведущие нули удаляются после проверки длины входной записи. Ноль хранится как одна цифра `0` со знаком `1`.

### Представление действительного числа

```c
#define BIG_FLOAT_MAX_DIGITS 30
#define EXPONENT_MAX_DIGITS 5

typedef struct
{
    int sign;
    size_t len;
    int exponent;
    unsigned char digits[BIG_FLOAT_MAX_DIGITS];
} big_float_t;
```

Поля `sign`, `len` и `digits` описывают знак и цифры мантиссы. Поле `exponent` хранит порядок со знаком. Положение десятичной точки отдельно не хранится: она подразумевается перед первой цифрой массива.

### Представление результата

```c
#define RESULT_MAX_DIGITS 40

typedef struct
{
    int sign;
    size_t len;
    int exponent;
    unsigned char digits[RESULT_MAX_DIGITS];
} result_t;
```

### Вспомогательные данные

Для точного промежуточного произведения используется массив `unsigned int product[70]`, поскольку произведение чисел из 40 и 30 цифр содержит не более 70 цифр. В функции разбора действительного числа используется массив `raw_digits[31]`

Длины массивов и индексы имеют тип `size_t`. Коды ошибок описаны перечислением `error_t` в файле `inc/errors.h`.

## Описание алгоритма

### Чтение и проверка данных

Функция `read_line` читает строку целиком с помощью `getline`, удаляет конечный символ перевода строки `\n` и предшествующий ему `\r`, если он присутствует. Затем проверяет непустоту строки и возможность размещения в переданном буфере. Допустимая строка копируется вместе с завершающим нулевым символом, после чего динамическая память освобождается.

При разборе целого числа определяется знак, проверяется наличие только цифр и ограничение на их количество. После удаления ведущих нулей цифры переносятся в `big_int_t`. Для нулевого значения знак приводится к положительному.

При разборе действительного числа выполняются следующие действия:

1. Определяется знак мантиссы.
2. До символа `E`, `e` или конца строки читаются цифры и необязательная точка. Повторная точка и посторонние символы вызывают ошибку.
3. Подсчитываются общее количество цифр и количество цифр до точки.
4. При наличии экспоненциальной части разбираются знак порядка и не более пяти его цифр. После них должен следовать конец строки.
5. Находится первая ненулевая цифра мантиссы. Если все цифры нулевые, создаётся представление нуля с порядком 0.
6. Вычисляется нормализованный порядок, а ведущие и конечные нули исключаются из сохраняемой мантиссы.

### Умножение мантисс

Если хотя бы один множитель равен нулю, результат сразу устанавливается равным `+0.0E+0`.

Для ненулевых множителей применяется умножение в столбик. Пусть целое число содержит `n` цифр, а мантисса действительного числа `m` цифр. Первые `n + m` элементов промежуточного массива обнуляются. Обход обоих массивов выполняется от младших цифр к старшим.

Для текущих индексов `i` и `j`, отсчитываемых в циклах от длины массива до 1, вычисляется:

```text
pos = i + j - 1;
value = product[pos] + integer.digits[i - 1] * real.digits[j - 1];
product[pos] = value % 10;
product[pos - 1] += value / 10;
```

Остаток от деления на 10 сохраняется в текущем разряде, а частное переносится в старший. После завершения циклов ведущие нули произведения удаляются сдвигом цифр к началу массива.

### Округление и вывод

Если точное произведение содержит не более 40 цифр, все они копируются в результат. В противном случае сохраняются первые 40 цифр и анализируется 41-я:

1. Если она меньше 5, оставшиеся цифры отбрасываются.
2. Если она не меньше 5, к 40-й цифре прибавляется единица.
3. Перенос распространяется в сторону старших разрядов через последовательность девяток.
4. Если все 40 сохранённых цифр были девятками, мантисса становится равной `0.1`, а порядок увеличивается на единицу.

После округления удаляются конечные нули мантиссы и проверяется диапазон порядка. При допустимом порядке выводятся знак, `0.`, цифры мантиссы, `E` и порядок с явным знаком.

### Оценка затрат

Основной алгоритм умножения выполняет `n * m` шагов, поэтому его временная сложность составляет `O(nm)`. Нормализация произведения и округление требуют `O(n + m)`.

Для промежуточного произведения требуется `O(n + m)` дополнительной памяти. В текущей реализации размер массива фиксирован и равен 70 элементам `unsigned int`.

## Вывод

В работе реализовано умножение целого числа длиной до 40 цифр на действительное число с мантиссой до 30 цифр. Для хранения значений использованы структуры с массивами десятичных цифр, отдельными полями знака, длины и порядка. Такое представление позволяет выполнять вычисления без преобразования исходных длинных чисел в стандартные целые или вещественные типы.

Алгоритм умножения в столбик сохраняет точное промежуточное произведение длиной до 70 цифр. Округление выполняется один раз, при формировании результата из не более чем 40 значащих цифр. Временная сложность умножения составляет `O(nm)`, дополнительная память для произведения составляет `O(n + m)`.

## Контрольные вопросы

### 1. Каков возможный диапазон чисел, представляемых в ПК?

Диапазон определяется выбранным типом данных, количеством разрядов и способом представления числа. Для беззнакового целого типа с `k` значащими двоичными разрядами диапазон составляет от 0 до `2^k - 1`. Для знакового целого в дополнительном коде с `k` разрядами, включая знаковый, он составляет от `-2^(k - 1)` до `2^(k - 1) - 1`.

Например, 32-битное знаковое целое в дополнительном коде принимает значения от `-2147483648` до `2147483647`. Диапазон вещественного типа зависит прежде всего от диапазона порядка и также от формата мантиссы. В распространённом формате IEEE 754 binary64 наибольшее конечное значение по модулю приблизительно равно `1.798 * 10^308`, а наименьшее положительное ненулевое субнормальное значение приблизительно равно `4.94 * 10^(-324)`.

Эти примеры не являются универсальными характеристиками всех типов языка C. Границы конкретной реализации задаются в `<limits.h>` и `<float.h>`. Разрядность процессора сама по себе не ограничивает длину программно представляемого числа: для длинной арифметики можно использовать массивы.

### 2. Какова возможная точность представления чисел, чем она определяется?

Целые числа в пределах диапазона целого типа представляются точно. Для вещественных чисел точность определяется основанием системы счисления и количеством значащих разрядов мантиссы. Увеличение числа разрядов порядка расширяет диапазон, но само по себе не увеличивает число сохраняемых значащих цифр.

### 3. Какие стандартные операции возможны над числами?

Над стандартными арифметическими типами C определены сложение, вычитание, умножение, деление, унарные плюс и минус, сравнения. Для целых типов также определены остаток от деления и побитовые операции. При целочисленном делении дробная часть результата отбрасывается. Математическая библиотека предоставляет функции вычисления корней, степеней, логарифмов и другие операции над вещественными типами.

### 4. Какой тип данных может выбрать программист, если обрабатываемые числа превышают возможный диапазон представления чисел в ПК?

Можно использовать массив цифр или блоков цифр, объединённый в структуру с длиной, знаком и, при необходимости, порядком. Массив может иметь фиксированный размер, если предельная длина известна, либо выделяться динамически.

### 5. Как можно осуществить операции над числами, выходящими за рамки машинного представления?

Операция разбивается на действия над отдельными цифрами или блоками, каждое из которых помещается в стандартный тип. Сложение и вычитание выполняются с переносами и заёмами, умножение с накоплением частичных произведений, деление с последовательным определением цифр частного. Знак и порядок обрабатываются отдельно.
