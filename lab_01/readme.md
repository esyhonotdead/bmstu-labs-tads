## Обработка больших чисел

Цель работы – реализация арифметических операций над числами, выходящими за разрядную сетку персонального компьютера, выбор необходимых типов данных для хранения и обработки указанных чисел.

Смоделировать операцию умножения целого числа длиной не более 40 десятичных цифр на действительное число в форме ±m.n Е ±K, где суммарная длина мантиссы (m+n) ≤ 30 значащих цифр, а величина порядка K ≤ 5 цифр. Результат выдать в форме ±0.m1 Е ±K1, где m1 – не более 40 значащих цифр, а K1 – не более 5 цифр.

## Формат ввода

1. Целое число с необязательным знаком, содержащее не более 40 цифр.
2. Действительное число с необязательным знаком, десятичной точкой и порядком `E`. Мантисса должна содержать не более 30 цифр, порядок — не более 5 цифр.

Примеры допустимых действительных чисел: `-12.5E+10`, `.125E-3`, `10`, `1E5`.

Результат выводится в нормализованном виде `±0.mE±K`. Если точное произведение содержит более 40 значащих цифр, оно округляется по 41-й цифре. При превышении пятизначного порядка программа сообщает об ошибке.

## Сборка и запуск

```sh
make
make run
```

Для удаления результатов сборки:

```sh
make clean
```
